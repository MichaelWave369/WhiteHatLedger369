# WhiteHatLedger369 🛡️

**The Ethical Reverse Lab** | PHI369 Security & Adversarial Assurance

> Break only what you are allowed to heal. Test only what you own or are explicitly authorized to examine. Every action earns a receipt.

WhiteHatLedger369 is a consent-first, evidence-led security assurance project. Its first milestone, **R0: The Watchtower**, is a **read-only, public-repository inventory**. R0 **does not scan for vulnerabilities, prove security, or access private repositories**.

## Founding principles

- **Authorization first:** no intrusive tests without documented asset ownership or explicit written permission.
- **Evidence before claims:** unknown is not secure, a passing build is not a security audit.
- **Public verifier, private keys:** never expose tokens or credentials in browser applications.
- **Safe-by-default tooling:** R0 uses only public GitHub metadata endpoints.
- **Receipts for everything:** future security findings require scope, proof, remediation, and retest evidence.

See the R0 implementation and threat model in the project branch and the original June 2026 master specification, `WhiteHatLedger369_Ethical_Reverse_Lab_Master_Spec_v0.1.docx`.
